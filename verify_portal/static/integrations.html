Integrations

Capture from your stack

EPI does not replace your agent framework. It wraps or hooks the run so steps land in a sealed .epi. Core package is Python 3.11+; many integrations are optional extras.

OpenAIwrap_openai(OpenAI()) — chat capture, streaming-aware paths with known limits.
Anthropicwrap_anthropic(...) — same wrap pattern for Messages API.
LiteLLMGlobal callbacks via enable_epi for multi-provider routing.
LangChainEPICallbackHandler on chains/agents.
LangGraphCheckpoint / record_langgraph helpers.
OpenTelemetryEPISpanExporter — bridge spans into steps.
pytestpytest --epi plugin — evidence from tests / CI.
AGTImport/export adapters for AGT-shaped traces.
GuardrailsOptional bridge package for guardrail events.
Gateway proxySelf-host LLM proxy capture via epi gateway.

Minimal path

pip install epi-recorder
# optional: pip install epi-recorder[openai]
from openai import OpenAI
from epi_recorder import record, wrap_openai

client = wrap_openai(OpenAI())
with record("agent.epi", goal="demo"):
    client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": "Hello"}],
    )
