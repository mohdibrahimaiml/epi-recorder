Integrations

Capture from your stack

EPI does not replace your agent framework. It wraps or hooks the run so steps land in a sealed .epi. Core package is Python 3.11+. The OpenAI and Anthropic wrappers, the LangChain callback and the pytest plugin are free; the other framework adapters (LangGraph, LiteLLM, OpenTelemetry), guardrails and the gateway ship with the epi-enterprise package (Growth, Enterprise and the full engagement).

OpenAIwrap_openai(OpenAI()) — chat capture, streaming-aware paths with known limits.
Anthropicwrap_anthropic(...) — same wrap pattern for Messages API.
LiteLLMGlobal callbacks via enable_epi for multi-provider routing. epi-enterprise.
LangChainEpiCallbackHandler(session) (from epi_recorder.adapters.langchain) inside with record(...) as session.
LangGraphCheckpoint / record_langgraph helpers. epi-enterprise.
OpenTelemetryEPISpanExporter — bridge spans into steps. epi-enterprise.
pytestpytest --epi plugin — evidence from tests / CI.
AGTImport/export adapters for AGT-shaped traces.
GuardrailsOptional bridge package for guardrail events. epi-enterprise.
Gateway proxySelf-host LLM proxy capture via epi gateway. epi-enterprise.

Minimal path

pip install epi-recorder
# optional: pip install epi-recorder[openai]
from openai import OpenAI
from epi_recorder import record, wrap_openai

client = wrap_openai(OpenAI())
with record("agent.epi", goal="demo"):
    client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": "Hello"}],
    )
