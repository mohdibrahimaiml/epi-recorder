Acceptance gate

What PASS means for security and CI.

Modes

  • Air-gapped seal: EPI_NOTARIZE=0
  • Standard seal: RFC 3161 on by default (network at seal only)
  • Verify / view: integrity + signature offline; identity from local trust store

What PASS means

  • Claims / insurers: always epi verify --policy strict (integrity + org-pinned sealer + completeness)
  • --review Binding True → human review bound to sealed evidence
  • Standard default: unpinned sealer → WARN · UNVERIFIED IDENTITY (valid seal ≠ known who; not claim-ready)
