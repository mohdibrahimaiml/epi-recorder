# Store screenshots

The four images described in `../microsoft-store-listing.md` go here, at
**1920 × 1080**, PNG:

| File | Shows |
|---|---|
| `01-viewer-record.png` | The viewer on the public sample: inputs, decision, reason |
| `02-checks-valid.png` | The integrity and signature lines with their result |
| `03-terminal-verify.png` | `epi verify sample.epi --policy strict` and its report |
| `04-demo.png` | `epi demo --no-browser`, sealed file and closing panel |

Rules:

- Public sample files only (`https://epilabs.org/assets/sample.epi`). No customer
  records, no personal data.
- No local paths, usernames, unrelated windows, or the SmartScreen dialog.
- Take them on the machine where the package is installed, not from a mock-up.

Until these exist, Partner Center cannot complete a submission: it requires at
least one screenshot.
