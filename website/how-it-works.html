Architecture & Wire Specification · v4.7.0

Inside an Envelope v2 evidence file.

Every .epi artifact is a self-contained HTML+ZIP polyglot binary. It opens in any browser with zero dependencies and extracts programmatically for offline cryptographic verification. 

demo.epi (Envelope v2)
├── [0..127] 128B Envelope Header
├── Embedded HTML Viewer (SHA-256 covered)
└── ZIP Payload
    ├── mimetype (application/vnd.epi+zip)
    ├── manifest.json (Ed25519 + JCS)
    ├── steps.jsonl (prev_hash chain)
    ├── environment.json (redacted)
    ├── policy.json & policy_evaluation.json
    └── artifacts/notarization/ (RFC 3161)
