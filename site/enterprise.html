Enterprise

EPI is a file-first evidence layer for enterprises — not a dashboard login. Portable cryptographic evidence, org key trust, policy checks, Annex tooling, CI gates. Optional hosted verify/SCITT for scale. Self-host when you must.

15-minute path

Two commands for your engineer. No dashboards. No API keys required for a pilot pack.

$ pip install epi-recorder
$ epi enterprise setup
# record one agent run → your-run.epi
$ epi enterprise pack your-run.epi
# → send auditor-pack.zip to security / audit

Acceptance gate — what PASS means

  • Air-gapped seal: EPI_NOTARIZE=0
  • Standard seal: RFC 3161 on by default (network at seal only)
  • Claims / insurers: always epi verify --policy strict (integrity + org-pinned sealer + completeness)
  • --review Binding True → human review bound to sealed evidence
  • Standard default: unpinned sealer → WARN · UNVERIFIED IDENTITY (valid seal ≠ known who; not claim-ready)
